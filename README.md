# 麦肯锡100年知识库 Skill

> 涵盖191篇精选内容，融合金字塔原理、结构化战略思维、麦肯锡工作法及全球行业洞察报告

## 概览

本Skill来源于IMA知识库，整合了两个麦肯锡专题知识库：
- **麦肯锡100年知识库** (183篇) — 方法论书籍、行业报告、全球洞察
- **麦肯锡思维模型** (123篇) — 100+顶级思维模型视觉化图集

去重后共 **191篇文本内容**（178 PDF + 13 PDF）。

## 知识架构

### Module 1: 核心方法论
- 金字塔原理 (MECE)
- 结构化战略思维
- 假设驱动问题解决
- Issue Tree逻辑树
- 4S法
- 零基准思考

### Module 2: 工作技能
- 麦肯锡工作法
- 麦肯锡写作法
- 麦肯锡阅读法
- 麦肯锡沟通法
- 学会提问
- 效率手册

### Module 3: 行业洞察报告
- 金融业（消费金融、资产管理、银行利率、养老金）
- 人工智能（生成式AI、AI代理、人才战略）
- 消费市场（新常态消费、用户研究）
- 能源与气候（碳减排、量子技术）
- 汽车行业（电动汽车转型）
- 宏观经济（劳动力市场、关税、数字化转型）

### Module 4: 思维模型图集
- 战略分析模型（安索夫、波特五力、BCG矩阵、SWOT）
- 决策框架模型（决策矩阵、情景规划、六顶思考帽）
- 问题拆解模型（5W2H、5Whys、鱼骨图）
- 创新思维模型（SCAMPER、设计思维、蓝海战略）
- 系统思考模型（系统循环图、冰山模型、杜邦分析）
- 沟通与影响力模型（SCQA、影响力六原则、RACI）
