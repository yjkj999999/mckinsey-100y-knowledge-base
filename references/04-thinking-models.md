## 模型分类体系

### 一、战略分析模型

#### 1. 安索夫矩阵 (Ansoff Matrix)
```
           现有产品    新产品
现有市场   市场渗透    产品开发
新市场     市场开发    多元化
```
- **用途**: 制定增长战略
- **风险**: 从左上到右下递增

#### 2. 波特五力模型 (Porter's Five Forces)
```
        新进入者威胁
           ↓
供应商议价 ← 行业竞争 → 买方议价
           ↑
        替代品威胁
```
- **用途**: 分析行业竞争格局
- **关键**: 五力的综合强度决定行业吸引力

#### 3. BCG矩阵 (波士顿矩阵)
```
        高增长
明星   │  问题
──────┼──────
现金牛│  瘦狗
        低增长
  高份额    低份额
```
- **用途**: 产品组合管理
- **策略**: 明星→投资；现金牛→收割；问题→选择性投资；瘦狗→退出

#### 4. 价值链分析 (Value Chain)
```
基础活动:  入站物流 → 运营 → 出站物流 → 营销销售 → 售后服务
支持活动:  采购 / 技术开发 / 人力资源 / 企业基础设施
```
- **用途**: 识别竞争优势来源

#### 5. SWOT分析
```
         有利因素    不利因素
内部     S 优势      W 劣势
外部     O 机会      T 威胁
```
- **用途**: 战略定位和决策

### 二、决策框架模型

#### 6. 决策矩阵 (Decision Matrix)
| 权重 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|
| 成本 (0.3) | 8 | 6 | 7 |
| 效率 (0.3) | 7 | 9 | 6 |
| 风险 (0.2) | 6 | 5 | 8 |
| 可行性 (0.2) | 7 | 6 | 9 |
| **加权总分** | **7.1** | **6.7** | **7.2** |

#### 7. 情景规划 (Scenario Planning)
- **最佳情景**: 一切顺利时的结果
- **基准情景**: 最可能的结果
- **最差情景**: 关键风险发生时的结果
- **黑天鹅情景**: 极端不确定事件

#### 8. 六顶思考帽 (Six Thinking Hats)
| 颜色 | 角度 | 关注点 |
|------|------|--------|
| 白 | 事实 | 数据和信息 |
| 红 | 情感 | 直觉和感受 |
| 黑 | 谨慎 | 风险和问题 |
| 黄 | 乐观 | 价值和利益 |
| 绿 | 创新 | 替代和创意 |
| 蓝 | 过程 | 思考的思考 |

### 三、问题拆解模型

#### 9. 5W2H分析法
- **What**: 做什么？
- **Why**: 为什么做？
- **Who**: 谁来做？
- **When**: 什么时候做？
- **Where**: 在哪里做？
- **How**: 怎么做？
- **How much**: 需要多少资源？

#### 10. 5 Whys (五问法)
```
问题：客户流失率上升
Why1: 客户满意度下降
Why2: 产品交付延迟
Why3: 供应链中断
Why4: 关键供应商产能不足
Why5: 供应商未提前预警产能瓶颈
→ 根因: 缺乏供应商产能监控预警机制
```

#### 11. 鱼骨图 (因果图)
```
        人员    流程
         \     /
          \   /
           骨干 ──→ 问题(效果)
          /   \
         /     \
       设备    环境
```

### 四、创新思维模型

#### 12. SCAMPER创新法
- **S**ubstitute: 替代
- **C**ombine: 组合
- **A**dapt: 适应
- **M**odify: 修改
- **P**ut to other use: 其他用途
- **E**liminate: 消除
- **R**earrange: 重组

#### 13. 设计思维 (Design Thinking)
```
同理心 → 定义问题 → 创意发想 → 原型制作 → 测试验证
   ↑                                            ↓
   └──────────── 迭代优化 ←───────────────────────┘
```

#### 14. 蓝海战略画布
- 横轴: 行业关键竞争因素
- 纵轴: 投入水平（高/中/低）
- 红海: 与竞争对手相似的曲线
- 蓝海: 差异化的曲线（Eliminate-Reduce-Raise-Create）

### 五、系统思考模型

#### 15. 系统循环图
```
    销售增长 ──→ 收入增加 ──→ 营销投入 ──→ 品牌认知
       ↑                                          │
       └────────── 市场份额 ←─────────────────────┘
```

#### 16. 冰山模型
```
     事件 (可见的)
    ───────────── 水面
     模式 (趋势)
     结构 (因果关系)
     心智模型 (信念假设)
```

#### 17. 杜邦分析法
```
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/收入) × (收入/资产) × (资产/权益)
```

### 六、沟通与影响力模型

#### 18. SCQA故事框架
- **S**ituation: 背景 — 建立共识
- **C**omplication: 冲突 — 引发关注
- **Q**uestion: 问题 — 聚焦思考
- **A**nswer: 回答 — 提供方案

#### 19. 影响力六原则 (Cialdini)
1. **互惠**: 先给予，再索取
2. **承诺一致**: 小承诺引导大行动
3. **社会认同**: 他人行为影响决策
4. **权威**: 专业性和可信度
5. **喜好**: 相似性和亲和力
6. **稀缺**: 限时限量增加价值感

#### 20. RACI矩阵
| 任务 | R(执行) | A(负责) | C(咨询) | I(知会) |
|------|---------|---------|---------|---------|
| 分析 | 分析师 | 项目经理 | 业务方 | 管理层 |
| 方案 | 顾问 | 合伙人 | 客户 | 团队 |
| 汇报 | 项目经理 | 合伙人 | 团队 | 客户 |

## 模型选择指南

| 需求 | 推荐模型 |
|------|----------|
| 制定增长战略 | 安索夫矩阵 + BCG矩阵 |
| 分析竞争格局 | 波特五力 + SWOT |
| 拆解复杂问题 | Issue Tree + 5 Whys + 鱼骨图 |
| 做重要决策 | 决策矩阵 + 情景规划 |
| 推动创新 | SCAMPER + 设计思维 + 蓝海战略 |
| 理解系统性问题 | 系统循环图 + 冰山模型 |
| 沟通汇报 | SCQA + 金字塔原理 |
| 团队协作 | 六顶思考帽 + RACI矩阵 |
| 说服影响 | 影响力六原则 + SCQA |
| 财务分析 | 杜邦分析法 + 价值链 |
