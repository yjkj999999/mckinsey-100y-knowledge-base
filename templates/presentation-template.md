# 麦肯锡幻灯片模板 (Ghost Deck)

## 幻灯片结构规范

### 每页核心原则
1. **标题即论点**: 标题是一个完整的陈述句，不是话题
2. **一个核心信息**: 每页只传达一个关键信息
3. **3-5个支撑点**: 用要点支撑核心论点
4. **图表优先**: 用数据可视化代替文字描述

---

### 标准幻灯片布局

#### 布局1: 标题+要点页
```
┌─────────────────────────────────────┐
│ [论点标题 - 完整陈述句]              │
├─────────────────────────────────────┤
│                                     │
│  ▸ [支撑要点1]                       │
│  ▸ [支撑要点2]                       │
│  ▸ [支撑要点3]                       │
│                                     │
│  [来源: 数据来源标注]                │
└─────────────────────────────────────┘
```

#### 布局2: 标题+图表页
```
┌─────────────────────────────────────┐
│ [论点标题 - 完整陈述句]              │
├──────────────┬──────────────────────┤
│              │                      │
│   [图表]     │   ▸ [要点1]          │
│              │   ▸ [要点2]          │
│              │   ▸ [要点3]          │
│              │                      │
└──────────────┴──────────────────────┘
```

#### 布局3: 2x2矩阵页
```
┌─────────────────────────────────────┐
│ [论点标题]                           │
├──────────────┬──────────────────────┤
│  [象限1]     │  [象限2]             │
│  - 要点      │  - 要点              │
├──────────────┼──────────────────────┤
│  [象限3]     │  [象限4]             │
│  - 要点      │  - 要点              │
└──────────────┴──────────────────────┘
```

---

### 标准报告结构 (15-20页)

| 页码 | 内容 | 布局 |
|------|------|------|
| 1 | 封面 | 标题+副标题 |
| 2 | 目录 | 流程图 |
| 3 | 执行摘要 | 要点页 |
| 4-5 | 背景与问题界定 | SCQA框架 |
| 6-7 | 分析框架 | Issue Tree |
| 8-10 | 核心发现 | 图表+要点 |
| 11-12 | 深入分析 | 2x2矩阵/趋势图 |
| 13-14 | 建议 | 行动路线图 |
| 15 | 下一步行动 | 时间线+负责人 |
| 16+ | 附录 | 数据表格 |

---

### 幻灯片标题示例

❌ **差标题** (只是话题):
- "市场分析"
- "竞争格局"
- "财务数据"

✅ **好标题** (完整论点):
- "中国市场增长主要来自二线城市的消费升级"
- "三大竞争对手中，A公司增长最快但利润率最低"
- "毛利率从35%下降到28%，主要受原材料成本上涨驱动"
